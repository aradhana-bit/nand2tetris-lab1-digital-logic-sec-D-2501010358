# nand2tetris-lab1-digital-logic-sec-D-2501010358
Lab 1: Digital Logic &amp; ALU Design — Implementation and verification of foundational combinational logic chips and the Hack ALU using NAND gates and Nand2Tetris HDL.


# Session 1 — Basic Digital Logic Gates

## Overview
This session focuses on the design and implementation of fundamental
digital logic gates using NAND gates as the universal building block.

## Topics Covered
- NOT Gate
- AND Gate
- OR Gate
- Truth Tables
- Boolean Logic
- Nand2Tetris HDL Implementation
- Hardware Simulation and Verification

## Objective
To understand the construction of basic logic gates from NAND gates
and verify their functionality using the Nand2Tetris Hardware Simulator.


# Session 2 — Combinational Logic and Multiplexing

## Overview
This session focuses on the implementation of intermediate
combinational logic circuits using Nand2Tetris HDL.

## Topics Covered
- XOR Gate
- 2-Way Multiplexer (Mux)
- 4-Way Multiplexer (Mux4Way16)
- Demultiplexer (DMux)
- Boolean Expressions
- HDL Implementation
- Hardware Simulation and Verification

## Objective
To understand how multiplexing and combinational logic circuits
are designed and implemented using HDL and verified through simulation.
